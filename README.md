## 📜 LA LEYENDA — SINOPSIS

> *"En las tierras del Santo Reino, la armonía se ha quebrado..."*

En las tierras del **Santo Reino**, la armonía se ha quebrado. Solo **Rodolfo**, un héroe inesperado, emprenderá una épica travesía que lo llevará a recorrer cada rincón del reino: desde sus **sierras más profundas** hasta sus **pueblos y fortalezas más antiguas**.

Su misión es recuperar las **Esferas Mágicas** esparcidas por todo el reino con un único fin: **resucitar a sus amigos caídos** y devolver la paz a su hogar.

En este viaje, no estará solo; deberá enfrentarse a **legiones de enemigos** atraídos por el poder de las esferas, quienes ansían reclamarlas para alcanzar la inmortalidad y someter al reino bajo su control eterno.

## 🚀 INSTALACIÓN Y EJECUCIÓN

### ▶️ Ejecutar el juego directamente

El ejecutable del juego se encuentra en la carpeta **`/juego`**. Si aún no tienes el proyecto, descárgalo de una de estas dos formas:

- **Con Git:** `git clone https://github.com/djsekai34/SuperRodolfoylasEsferasdelSantoReino`
- **Sin Git:** En GitHub, haz clic en el botón verde **`<> Code`** → **`Download ZIP`** y descomprímelo

Una vez descargado, encontrarás la carpeta `juego/` lista para ejecutar:

```
📁 SuperRodolfo/
└── 📁 juego/
    ├── 🎮 SuperRodolfo.exe      ← ¡EJECUTA ESTO!
    ├── SuperRodolfo_Data/
    ├── MonoBleedingEdge/
    └── UnityPlayer.dll
```

> **¡IMPORTANTE!** No muevas el `.exe` fuera de la carpeta `juego/`. El juego necesita todos los archivos de esa carpeta para funcionar correctamente.

**Pasos:**
1. Navega a la carpeta `juego/`
2. Haz doble clic en `SuperRodolfo.exe`
3. ¡El Santo Reino te espera! ⚔️

## 🧩 CLONAR Y ABRIR EL PROYECTO (Desarrolladores)

### Prerequisitos

Antes de clonar el proyecto, asegúrate de tener instalado:

- ✅ **Git** — [Descargar Git](https://git-scm.com/)
- ✅ **Unity Hub** — [Descargar Unity Hub](https://unity.com/download)
- ✅ **Unity 6.0 (6000.0.66f2)** — Instalable desde Unity Hub

### 1️⃣ Obtener el proyecto

Tienes dos opciones para descargarte el proyecto:

**Opción A — Clonar con Git (recomendado):**
```bash
# Clona el repositorio completo
git clone https://github.com/djsekai34/SuperRodolfoylasEsferasdelSantoReino

# Entra en la carpeta del proyecto
cd SuperRodolfoylasEsferasdelSantoReino
```

**Opción B — Descargar ZIP (sin Git):**
> En la página del repositorio de GitHub, haz clic en el botón verde **`<> Code`** → **`Download ZIP`**. Descomprime el archivo y ya tendrás el proyecto listo para abrir en Unity.

### 2️⃣ Abrir en Unity Hub

1. Abre **Unity Hub**
2. Haz clic en **"Add"** → **"Add project from disk"**
3. Selecciona la carpeta raíz del proyecto clonado
4. Asegúrate de que Unity Hub detecta la versión **6.0 (6000.0.66f2)**
5. Haz clic en el proyecto para abrirlo

### 3️⃣ Compilar el juego (Build)

Una vez abierto el proyecto en Unity:

```
File → Build Settings → PC, Mac & Linux Standalone
Target Platform: Windows
Architecture: x86_64
→ Build
```

Selecciona la carpeta `juego/` como destino del build.

## 👾 ENEMIGOS DEL SANTO REINO

El camino hacia las esferas estará plagado de peligros. Siete temibles guerreros han ido en busqueda de las esferas y juran acabar con Rodolfo para hacerse con el control del Santo Reino:

- 🧊 **Freezer** — Señor galáctico de destrucción sin piedad, su frío poder congela cualquier esperanza
- 💪 **Broly** — El Supersaiyano Legendario, una fuerza descontrolada de destrucción pura
- ⚡ **Kefla** — La fusión explosiva de dos guerreras letales, velocidad y potencia sin límite
- 👹 **Janemba** — Un demonio de otra dimensión que distorsiona la realidad a su antojo
- 🎯 **Hit** — El asesino más temido del universo, maestro del tiempo y la muerte silenciosa
- 🌑 **Turles** — El pirata espacial que cosecha planetas; ahora quiere cosechar el Santo Reino
- 🦂 **Cell** — La forma de vida perfecta, que absorbe y evoluciona para destruir todo lo que Rodolfo ama
